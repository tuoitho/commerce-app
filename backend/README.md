# commerce-backend

Go clean-architecture API for the commerce monorepo. PostgreSQL · Gin · sqlc generated code · golang-jwt.

## Layout

- `cmd/server` — entrypoint: loads config, connects DB, wires Gin router.
- `internal/config` — environment configuration with defaults and validation.
- `internal/domain` — entities, domain errors, repository interfaces.
- `internal/usecase/auth` — application logic (register, login, refresh, logout, me).
- `internal/repository` — sqlc-backed implementations of the domain interfaces.
- `internal/repository/sqlc` — generated by `sqlc generate` (committed, do not edit).
- `internal/security` — bcrypt password hashing, opaque refresh-token generation, JWT manager.
- `internal/delivery/http` — Gin handlers, error mapping, auth guard middleware.
- `db/migrations` — golang-migrate numbered SQL files.
- `db/queries` — SQL source consumed by sqlc.

## Prerequisites

- Go 1.25+
- PostgreSQL running locally
- `sqlc` and `migrate` CLI on `PATH`
  - `go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest`
  - `go install -tags postgres github.com/golang-migrate/migrate/v4/cmd/migrate@latest`

## Setup

1. Create the database and owner:

   ```sql
   CREATE ROLE commerce LOGIN PASSWORD 'commerce' CREATEDB;
   CREATE DATABASE commerce OWNER commerce;
   ```

2. Apply migrations:

   ```sh
   make db-up
   ```

3. Configure environment — copy `.env.example` to `.env` (or export the variables) and set
   `DB_URL` and a `JWT_ACCESS_SECRET` of at least 32 characters.

## Run

```sh
make run
```

The server listens on `HTTP_PORT` (default `18080`). Routes live under `/api/v1`:

- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login`
- `POST /api/v1/auth/refresh`
- `POST /api/v1/auth/logout`
- `GET  /api/v1/auth/me` (requires `Authorization: Bearer <access-token>`)

## Test & verify

```sh
make test   # go test ./...
make vet    # go vet ./...
make gen    # sqlc generate
```

Generated sqlc code must remain in sync — after changing `db/migrations` or `db/queries`,
run `make gen` and commit the diff.

## Environment variables

See `.env.example` for the full list: `APP_ENV`, `HTTP_PORT`, `DB_URL`,
`JWT_ACCESS_SECRET`, `ACCESS_TOKEN_TTL`, `REFRESH_TOKEN_TTL`, `COOKIE_SECURE`.
