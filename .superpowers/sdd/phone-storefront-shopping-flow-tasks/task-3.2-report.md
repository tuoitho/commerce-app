## Implementation

- Added SQLC queries for user-row locking, variant/catalog lookup, cart reconciliation, live snapshot refresh, cart loading, conditional add/increment, item locking, quantity/selection mutations, select-all, and removal.
- Every repository operation starts a transaction, locks the caller's `users` row before cart or variant rows, reconciles inactive/zero-stock/insufficient-stock lines, performs the mutation, loads a full cart, and commits.
- Reconcile persists `selected=false` for unavailable lines and never changes quantity.
- `SetAllSelected(true)` only selects currently available lines; unavailable lines remain deselected.
- Live labels/snapshots are refreshed for active catalog records. Inactive product/variant lines use persisted snapshots.
- Available and insufficient-stock lines expose live unit and line prices. Unavailable and out-of-stock lines expose nil prices. Only selected available lines contribute to summary count and total.
- Monetary arithmetic uses `math/big.Int`; PostgreSQL numerics are mapped without narrowing to `int64`.
- Business rejection after reconciliation commits the reconciliation and returns the stable domain sentinel. Infrastructure errors roll back.
- Added `test-integration`, using `go test -tags=integration` with a mandatory Testcontainers PostgreSQL `17.6-alpine` container. Docker/container failures fail the test rather than skip.
